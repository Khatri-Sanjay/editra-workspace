# Columns and horizontal lines

Use columns when two parts of a document need independent side-by-side content. Use horizontal lines to separate sections visually. Both features are saved as document content.

## Add columns

1. Place the caret where you want a column layout.
2. Use the column insertion tool, or select an image and choose Add content beside image.
3. Click inside each column to write headings, paragraphs, lists, or media independently.

Adding content beside an image creates separate content areas rather than floating text around the image. This makes it possible to keep writing beside a tall image without merging that text into the image caption.

## Resize columns

Drag the divider between the columns to adjust their proportions. Release to commit; Escape cancels a preview. The column weights are retained when the document is saved and reloaded. Undo reverses a committed resize. Use the layout controls to restore equal proportions when needed.

Check the resulting content on narrow screens. Large media remains constrained by its available content area. If you render saved HTML separately, use the viewer so the shared responsive content styling is applied.

## Insert a horizontal line

Use Insert horizontal line to insert immediately using the current line settings. Open Line settings to choose the style and weight. The chosen settings are reused for subsequent insertions. Selecting an existing divider allows its appearance to be edited; saved HTML retains the supported divider attributes.

Dividers are visual separators, not a replacement for descriptive headings. See [formatting](FORMATTING.md) for document structure and [saved-content rendering](VIEWER.md) for displaying the result.
