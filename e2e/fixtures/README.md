# Media test fixture

`flower.mp4` is the MDN interactive example video, distributed under CC0 1.0 Universal.

-   Source: https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4
-   License: https://github.com/mdn/interactive-examples/blob/main/LICENSE

The browser tests serve this local file through an intercepted HTTPS URL. It is not
included in the published editor package and requires no network access during tests.
